# Chapter 11 printables

Sources for the four free downloads the book promises at halfpintmama.com/shop
(page 143): the Prep Day Planner, both stock-up lists, and the Freezer Inventory
Checklist. Content mirrors book pages 141 to 145 word for word; keep them in sync.

Render each with `~/.research/_hpm_checklist_pdf.mjs <html> <pdf>` (Chrome, Letter,
printBackground) into `public/downloads/` using the hashed names in
`src/lib/shop/printables.ts`, then refresh the page-1 previews with
`qlmanage -t -s 1200` and `sips -Z 900` into `public/images/printables/`.
